# SPIN Lab · Consultative Selling Studio

เว็บแอปฝึก **SPIN Selling** สำหรับตัวแทนประกันชีวิตและที่ปรึกษาทางการเงิน
(Next.js 16 + React 19, เก็บข้อมูลใน Vercel Blob แบบ private)

เนื้อหาอิงจาก *SPIN Selling Master* (Consultative Selling) และการ์ดลูกค้า 6 ใบของ AXA PRIME Onboarding Camp

## หน้าในแอป

### หลายห้องพร้อมกัน (สูงสุด 5 ห้อง)
- ทุกหน้าของคลาสใช้ `?room=1`–`?room=5` เช่น `/class/admin?room=2`, `/class/display?room=2` แต่ละห้องแยกผู้เรียน คะแนน และสมุด Post-it ออกจากกัน
- ผู้สอนสลับห้องได้จากแท็บด้านบนของหน้าผู้สอน (จุดสีเขียว = มีคนอยู่/มีกิจกรรม) และตั้งชื่อห้องได้ใน “ตั้งค่าห้อง”
- QR บนจอแต่ละห้องพาผู้เรียนเข้าห้องนั้นตรงๆ ถ้าเปิด `/class` เฉยๆ และมีหลายห้องเปิดอยู่ จะมีหน้าให้เลือกห้อง (ถ้ามีห้องเดียวจะเข้าเลย)

### 1. Role Play เป็นคู่ (`/pair`)
- สร้างห้อง แล้วส่งรหัส 6 ตัวหรือลิงก์ให้คู่ เลือกการ์ด (หรือสุ่ม) และเวลาได้ 5–20 นาที
- **ลูกค้า** เห็นภาพการ์ดจริง ข้อมูลบุคลิก ประโยคติดปาก และวิธีตอบในแต่ละขั้น S/P/I/N
  ระหว่างคุยกดอีโมจิบอกความรู้สึกได้ 8 แบบ เช่น สนใจ เริ่มเห็นภาพ เริ่มกังวล หรือรู้สึกโดนขาย
- **ตัวแทน** เห็นแถบ S › P › I › N ขนาดใหญ่ แตะไปขั้นไหนก็ได้ หรือกด ย้อนกลับ / ถัดไป
  แต่ละขั้นมีความหมาย เป้าหมาย ตัวอย่างประโยคสำหรับลูกค้ารายนั้น ตัวอย่างจากบทเรียน และข้อควรระวัง
  เมื่อลูกค้ากดความรู้สึก จะมีป๊อปอัปพร้อมคำแนะนำว่าควรทำอะไรต่อ
- จบแล้วลูกค้าให้คะแนน 5 ด้าน (S, P, I, N, Listening) รายงานส่งให้ตัวแทนเท่านั้น จากนั้นกดสลับบทเล่นรอบถัดไป
- ตัวแทนไม่สามารถเปิดดูการ์ดลูกค้าได้ (`/api/card` ตอบ 403)

### กำแพงลูกค้า (จากสไลด์ “กำแพงลูกค้า → เปิดใจ”)
ทุกรอบเริ่มที่ 80% ความรู้สึกที่ลูกค้ากดจะลด/เพิ่มกำแพง (เช่น ❤️ −12, 💡 −10, 😣 รู้สึกโดนขาย +15; 😟 กังวลในขั้น I ถือว่าดี −8)
ทั้งสองฝ่ายเห็นระดับกำแพงสด และรายงานท้ายรอบบอกว่าลูกค้าเปิดใจได้แค่ไหน

### เนื้อหาจากทีม Training Specialist
- การ์ดลูกค้าแต่ละใบมี **ความต้องการลึกๆ**, สิ่งที่ทำให้กำแพงลด/สูง (ลูกค้าเห็น), **ข้อโต้แย้ง 3 ข้อพร้อมวิธีตอบแบบ SPIN** และประโยคตัวอย่างเพิ่มขั้นละ 2 (ตัวแทนเห็น)
- ขั้น S มีเช็กลิสต์ 6 หัวข้อจากสไลด์ ทุกขั้นมี “พร้อมไปขั้นถัดไปเมื่อ” และประโยคเชื่อม ขั้น N มีขั้นตอน Present Solution
- เนื้อหาอยู่ที่ `lib/content.ts` (ใช้ฝั่ง client ได้) และ `lib/server/persona-extra.ts` (server เท่านั้น)

### 2. เกมทาย SPIN (ทั้งคลาส)
- คลังคำถาม 40 ข้อ แบ่งเป็น S, P, I, N อย่างละ 10 ข้อ (ข้อ 21–40 มีข้อหลอก เช่น S/P, I/N) อยู่ใน `lib/server/quiz-bank.ts` ทุกเกมสุ่มแบบสมดุลทั้ง 4 ขั้น
  เฉลยเก็บไว้ฝั่ง server ผู้เล่นจึงเปิดดูคำตอบจากมือถือไม่ได้
- ผู้สอนเลือกจำนวนข้อ (3–20) และเวลาต่อข้อ (10/15/20/30 วินาที) ระบบสุ่มลำดับคำถามให้
- ตอบถูกได้ 500–1000 คะแนน ยิ่งตอบเร็วยิ่งได้มาก ตอบผิดได้ 0
  คะแนนเท่ากันให้คนที่ตอบถูกมากกว่าชนะ ถ้ายังเท่ากันให้คนที่ใช้เวลารวมน้อยกว่าชนะ
- ระบบเฉลยอัตโนมัติเมื่อหมดเวลา (ต้องเปิดหน้าผู้สอนค้างไว้) จอ Live แสดงกราฟคำตอบ คนที่ตอบเร็วที่สุด และกระดานคะแนน
  จบเกมแสดงโพเดียม 3 อันดับแรก

### 3. Post-it คิดคำถาม (จากกิจกรรมในสไลด์)
- ผู้สอนเลือกขั้น (S/P/I/N) โจทย์ลูกค้า และเวลา 2/3/5/7/10 นาที ผู้เรียนเขียนคำถามคนละ 1 ข้อบนมือถือ
- ระหว่างเขียน ผู้สอนกด “หยุดเวลา” ได้ (เช่น หมดเวลาแล้วแต่ยังมีคนไม่ส่ง) ระหว่างหยุดผู้เรียนยังส่ง/แก้ได้ กด “เดินเวลาต่อ” เมื่อพร้อม หรือ “+1/+2/+3/+5 นาที” เพื่อเพิ่มเวลา
- เมื่อปิดรับ กระดานจะถูกเก็บใน “สมุด Post-it” ของห้อง ผู้เรียนเปิดอ่านซ้ำจากมือถือได้ บันทึกเป็นรูป (มือถือจะเปิดเมนูแชร์ → บันทึกรูป) หรือพิมพ์/บันทึก PDF ทั้งเล่ม
- Post-it ซ่อนไว้จนผู้สอนกด “เปิดกระดาน” แล้วขึ้นจอพร้อมกัน ผู้สอนติดดาว ⭐ คำถามตัวอย่างที่ดีได้ และมีคำแนะนำสำหรับ Mentor ทุกขั้น

### 4. SHOW TIME · Feedback คู่หน้าห้อง (SPIN + Present Solution)
- ผู้สอนใส่ชื่อตัวแทน ลูกค้า การ์ด และเวลา (ค่าเริ่มต้น 10 นาที) แล้วกด **เริ่ม Role Play** จอ Live นับถอยหลังและแสดง 6 ด้านที่ต้องสังเกต
- ผู้สอนกด **จบ Role Play** เมื่อคุยจบ ผู้เรียนทุกคนจึงให้คะแนนตัวแทนได้
  ฟอร์มมีคะแนน 1–5 ทั้ง 6 ด้าน (S, P, I, N, Listening, Present Solution) แท็กจุดเด่น/ควรพัฒนา และความเห็น (ไม่บังคับ)
- หน้าผู้สอนมีเกณฑ์ให้คะแนน 1/3/5 สำหรับ Mentor / Coach
- ผู้สอนกด **ปิดรับ** แล้วจอ Live สรุปผล: คะแนนเฉลี่ยรวม คะแนนแต่ละด้าน ด้านที่เด่นและควรฝึก แท็กยอดนิยม และความเห็นแบบไม่ระบุชื่อ
- เล่นครบหลายคู่แล้วกด **สรุปทุกคู่บนจอ** เพื่อจัดอันดับทุกคู่
- หน้าผู้สอนกด Space หรือ → แทนการกดปุ่มหลักได้

## Mode & Tone · เสียงประกอบ
- แนวคิดดีไซน์ "course studio": หัวข้อ serif แบบ editorial (Fraunces + Noto Serif Thai), UI ด้วย Bricolage Grotesque + IBM Plex Sans Thai,
  พื้นกระดาษโทนอุ่น เส้นหมึก + เงาแข็ง (chunky แบบเกม) และสติกเกอร์ไอคอนเอียงเล็กน้อย ฟอนต์โหลดผ่าน `<link>` ใน `app/layout.tsx`
- สัญลักษณ์ 4 ขั้น: S วงกลม · P สี่เหลี่ยม · I สามเหลี่ยม · N ดาว (`components/icons.tsx`) ใช้บนแบดจ์ ปุ่มตอบ และโลโก้ของแอป
- โทนสี AXA (ไม่ใช้โลโก้ AXA): น้ำเงิน `#00008F` เป็นหลัก แดง `#FF1721` เป็นสีเน้น เหลือง highlighter เป็นสีเล่น
  สี S/P/I/N: น้ำเงิน / เขียวน้ำทะเล / แดง / เขียว แก้ได้ที่ `:root` ใน `app/globals.css` และ `lib/spin.ts`
- เกมทาย SPIN แบบเกมโชว์: ห้องรอมีชื่อผู้เล่นเด้งขึ้นจอ → โชว์คำถามให้อ่าน 3.5 วินาที → ปลดล็อกปุ่ม S/P/I/N เต็มจอมือถือ
  → หน้าผลบนมือถือเป็นสีเขียว/แดง พร้อมคะแนน สตรีค 🔥 อันดับ และระยะห่างจากคนข้างหน้า → โพเดียมเปิดทีละอันดับ 3 › 2 › 1 พร้อมพลุ
- เสียงทั้งหมดสังเคราะห์ด้วย Web Audio (`lib/sound.ts`) ไม่มีไฟล์เสียง: เพลงห้องรอ เพลงระหว่างคิด เสียงนับถอยหลัง หมดเวลา ถูก/ผิด เฉลย กลองรัว และแตรฉลองผู้ชนะ
  จอ Live ต้องคลิกหนึ่งครั้งเพื่อเปิดเสียง (นโยบายเบราว์เซอร์) และปุ่ม 🔊 ใช้ปิด/เปิดเสียงได้ทุกหน้า

## ตั้งค่าบน Vercel

| Environment variable | ใช้ทำอะไร |
|---|---|
| `BLOB_READ_WRITE_TOKEN` | เชื่อม Vercel Blob (Storage → Blob → Connect to project จะตั้งให้เอง) |
| `LIVE_ADMIN_KEY` | รหัสเข้าหน้าผู้สอน และใช้ลงลายเซ็น token ของผู้เล่น |
| `CRON_SECRET` | ป้องกัน `/api/cleanup` ซึ่งลบห้องที่เก่ากว่า 4 ชม. และข้อมูลคลาสที่เก่ากว่า 24 ชม. ทุกชั่วโมง |

Preview deployment แยกข้อมูลไว้ใต้โฟลเดอร์ `preview/` ไม่ปนกับ production

## รันในเครื่อง

```bash
npm install

npm test        # unit tests: logic ของเกมคู่ เกมทาย และ Feedback

```
